# BAND 2.6.0 — Owner-first estimator

- Replaced long stage and finish dropdowns with compact choice cards.
- Results now show an executive budget, material/labor planning allowances, key quantities, optional trade cost split, and grouped material purchase ranges.
- Updated stage multipliers for pre-masonry and on-brick estimates to include a preliminary allowance for internal masonry/plastering differences against plastered-unit published comparisons.
- Added explicit scope note for apartment vs repeated-unit building estimates; structural frame, foundations, kitchen joinery, A/C, appliances and furniture remain excluded unless separately quantified.
- Added methodology, public price references and dataset requirements; does not claim model training on real BOQs.
