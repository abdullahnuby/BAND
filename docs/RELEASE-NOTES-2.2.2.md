# ملاحظات الإصدار 2.2.2 — مراجعة منطق الحصر

- فصل سجل جسم حائط المباني عن وجوه الحوائط المستخدمة للمحارة والدهانات، لمنع عد الحائط المشترك مرة لكل غرفة.
- اقتراح م² عند سمك 12 سم وم³ عند 25 سم، مع طلب اختيار صريح لوحدة المقايسة عند السماكات الملتبسة، وإتاحة التجاوز اليدوي حسب العقد.
- فحص أبعاد كل فتحة منفردة وليس مجموع المساحات فقط.
- توحيد تعريف السجل المكرر مع تطبيع النصوص والأرقام، وجعل مفاتيح التكرار تتغير حسب وحدة العزل (م²/م³/م طولي/عدد).
- حظر خصومات التداخل السالبة أو الأكبر من حجم العنصر، ومنع التقرير/التصدير/المزامنة عند وجود ملاحظات هندسية.
- تحديث شيتات التقارير وفصل وحدات المباني والعزل وعدم جمع وحدات غير قابلة للجمع.
- اختبارات الوحدة: 14/14 ناجحة، والبناء وفحص JavaScript ناجحان.

**حدود معروفة:** كشف التطابق يعتمد على الموقع/المحور والأبعاد المسجلة؛ لا يمكن استنتاج التداخل المكاني الكامل بين عناصر أدخلت بمراجع مختلفة دون إحداثيات أو نماذج هندسية.
